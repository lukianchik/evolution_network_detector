# Changelog

## 1.0.0 — Initial public release

- Unified CPU evolution engine for Local and Hybrid with adaptive strategy selection, error-driven mutations and bounded Pareto selection.
- Structured, interpretable rules with weighted Boolean groups and intervals; restricted Python evaluation and export.
- Grouped, stratified UNSW-NB15 sampling, data-quality audit, internal reserve and reproducible sample fingerprints.
- Local web panel with experiment controls, Pareto charts, candidate diffs and an archive of runs.
- Docker Compose deployment with private MCP Streamable HTTP, isolated provider credentials and persistent run artifacts.
- Optional budgeted Groq assistance and experimental ShinkaEvolve CLI comparison.
- Multi-seed benchmarks, ablations, final evaluation, automated checks and bilingual documentation.
