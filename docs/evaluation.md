Лидер `r69`, SHA-256 программы `5eb41d0ce3e6a436cb04ae3fd6c250ce5588b3d594e867f5d561aba53ad179f8`. Поиск использовал 49 910 train и 4 484 validation строк. 23 проверки MCP прошли без ошибок. Groq не вызывался.

| Раздел | F1 | Precision | Recall | FPR | Fitness |
|---|---:|---:|---:|---:|---:|
| Validation | 0.943726 | 0.966865 | 0.921668 | 0.075873 | 0.928551 |
| Официальный test | 0.878478 | 0.853063 | 0.905453 | 0.191081 | 0.840262 |

На полном официальном test из 82 332 строк получены TP 41 046, FP 7 070, FN 4 286 и TN 29 930. Recall по Fuzzers составил 0.4810, по Generic — 0.9955. Исходный полный разрез по категориям и артефакты запуска в репозиторий не включены. Официальный test ранее анализировался при разработке и не является слепой контрольной выборкой. Результат относится к зафиксированному правилу и этому набору. [Ограничения датасета](research.md)

На seed 42–46 Local и Hybrid с нулевым бюджетом Groq дали одинаковые результаты на общем внутреннем validation. F1 составил 0.9224 ± 0.0216, FPR 0.0985 ± 0.0329, recall 0.8915 ± 0.0368, precision 0.9562 ± 0.0139. Значения после ± — выборочное стандартное отклонение. Каждый режим завершил пять запусков с потолком 24 поколений по 24 шага. Часть запусков остановилась раньше по критерию застоя.

```sh
python -m tools.benchmark --dataset unsw --modes local hybrid --seeds 42 43 44 45 46 --generations 24 --offspring 24 --train-size 50000 --llm-budget 0 --output results/reproduce-v1-validation
python -m search.local_evolution --mode hybrid --dataset unsw --budget deep --seed 42 --llm-budget 0 --output results/unsw-deep
python -m evaluation.final_test --run results/unsw-deep --output results/v1-final-r69.json
```

Команда поиска воспроизводит конфигурацию зафиксированного запуска (seed 42, deep, нулевой бюджет Groq); совпадение хеша зависит от данных, реализации и условий выполнения. Команда оценки использует полученный результат. CSV и локальные артефакты в Git не входят.

## Как читать счётчики

| Значение r69 | Смысл |
|---|---|
| 552 локальных шага | Вызовы локальных стратегий |
| 420 шагов с новыми правилами | Шаги, в которых хотя бы один кандидат прошёл train-отсев |
| 2 887 проверок правил на train | Построения предсказаний, включая 718 поведенческих дубликатов |

| 6 781 событие отсева | Повторные предложения, поведенческие дубликаты и недопустимые правила. Число учитывает события, поэтому один кандидат может встретиться несколько раз |

Отдельно записаны 794 проверки простых условий и 9 896 сравнений агрегированных ошибок. Скалярный fitness использует F1 − λ × FPR. Оценка профиля также учитывает целевые ограничения, сложность, устойчивость и разрыв train/validation. У r69 она равна 0.8973487. Максимальный наблюдавшийся F1 составляет 0.960 и принадлежит другой версии. Отрицательный Δfitness при смене лидера показывает изменение скалярной метрики.

## Ограничения

Полный официальный test содержит совпадения признаков с train. Данные не являются новым независимым захватом. Заявленные результаты относятся к исследовательскому протоколу, а не к промышленной IDS. Код распространяется по MIT; CSV и сторонние пакеты имеют отдельные условия. [Условия UNSW](https://research.unsw.edu.au/projects/unsw-nb15-dataset)
